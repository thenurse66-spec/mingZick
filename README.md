# mingZick
**Deine Zeit. Deine Entscheidung.**

Arbeitszeiterfassung für Android. Dieses Repository stellt APK-Testversionen und Installationshinweise bereit.

## Testversion herunterladen
Unter [Releases](https://github.com/thenurse66-spec/mingZick/releases) die gewünschte Version öffnen und im Bereich **Assets** die Datei mit der Endung **.apk** herunterladen. Die von GitHub automatisch angebotenen „Source code“-Archive sind keine Installationsdateien.

Die Testversionen sind Vorabversionen. Insbesondere nach einem Update sollten vorhandener Verlauf, Einstellungen und Standortautomatik kurz geprüft werden.

## Installation
1. Vor einem Update möglichst eine Datensicherung in der App erstellen.
2. Die APK auf dem Android-Handy herunterladen und öffnen.
3. Falls Android nachfragt, die Installation aus dieser Quelle für den verwendeten Browser bzw. Dateimanager erlauben.
4. Bei einer vorhandenen mingZick-Testversion **als Update installieren**; die App vorher nicht deinstallieren.
5. Nach der Installation Verlauf und Einstellungen prüfen. Falls nötig den Standortempfang und die Automatik wieder einschalten.

Version 0.10.7 hat dieselbe Paketkennung und Signatur wie die bisherige mingZick-Testversion 0.10.6. Die alte HoraLog-App mit anderer Paketkennung ist davon getrennt.

## Anleitung und Rückmeldung
Die ausführliche Anleitung ist in der App unter **Einstellungen → Hilfe & Anleitung** erreichbar. Für den geschützten Testbereich werden gesonderte Zugangsdaten benötigt.

Rückmeldungen bitte mit App-Version, Handymodell, Android-Version und den Schritten bis zum Problem an **kontakt@mingzick.de** senden. Bitte keine persönlichen Arbeitszeitdaten oder Standortdaten öffentlich in Issues einstellen.

## Prüfsumme
Zu jedem hier veröffentlichten APK-Download wird eine Datei **SHA256SUMS.txt** bereitgestellt, mit der die heruntergeladene Datei geprüft werden kann.

Dieses Repository enthält keine App-Quelltexte oder Signierschlüssel. Es wird keine Open-Source-Lizenz erteilt.
